# Тест-кейсы (Test Cases) для TaskFlow

# TC-001: Создание новой задачи (Позитивный сценарий)

**Приоритет:** High
**Тип:** Функциональное тестирование
**Окружение:**  Windows 11, Chrome (157.0.8103.39 (64 бит)), `http://127.0.0.1:5000`

**Предусловия (Preconditions):**
1. Сервер запущен (`python app.py`).
2. Открыта главная страница приложения.
3. Поле ввода пустое.

**Шаги воспроизведения (Steps to reproduce):**
1. Ввести текст "Купить хлеб" в поле ввода "Введите новую задачу...".
2. Нажать кнопку "Добавить".

**Ожидаемый результат (Expected result):**
1. Новая задача "Купить хлеб" появляется в списке ниже.
2. Статус задачи отображается как "todo".
3. Поле ввода очищается после добавления.
4. В БД (DBeaver) появляется новая запись.
5. API ввозвращает статус-код 201 Created.

**Фактический результат (Actual result):**
Совпадает с ожидаемым. Задача появилась в списке, поле очистилось. В DevTools статус 201 Created.

**Статус тест-кейса:**
PASS (Пройден).

## TC-002: Валидация пустого поля (Негативный сценарий)

**Приоритет:** High
**Тип:** Функциональное тестирование (Негативное)
**Окружение:**  Windows 11, Chrome (157.0.8103.39 (64 бит)), `http://127.0.0.1:5000`

**Предусловия (Preconditions):**
1. Сервер запущен (`python app.py`).
2. Открыта главная страница приложения.
3. Поле ввода пустое.

**Шаги воспроизведения (Steps to reproduce):**
1. Оставить поле ввода "Введите новую задачу..." пустым.
2. Нажать кнопку "Добавить".

**Ожидаемый результат (Expected result):**
1. Задача не создается (список не меняется).
2. Появляется сообщение об ошибке (в текущей реализации-Alert с текстом "Введите название задачи!").
3. Запрос на сервер (POST /api/tasks) НЕ отправляется.

**Фактический результат (Actual result):**
Совпадает с ожидаемым. Задача не создалась. Вылез Alert. В DevToolsзапрос POST не ушел.

**Статус тест-кейса:**
PASS (Пройден, но есть UX-баг BUG-001)
