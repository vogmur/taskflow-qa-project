# Баг-репорты (Bug Reports)

## BUG-001: Использование ситемного alert() вместо кастомного уведомления об ошибке

**Статус:** Открыт (Open)
**Приоритет (Priority):** Низкий (Low)
**Серьезность (Severity):** Незначительная (Minor)
**Окружение (Environment):** Windows 11, Chrome (157.0.8103.39 (64 бит)), `http://127.0.0.1:5000`

**Предусловия (Preconditions):**
1. Приложение запущено локально (`python app.py`).
2. Открыта главная страница.

**Шаги воспроизведения (Steps to reproduce):**
1. Оставить поле ввода "Введите новую задачу..." пустым.
2. Нажать кнопку "Добавить".

**Ожидаемый результат (Expected result):**
Под полем ввода появляется стилизованное сообщение об ошибке (например, красный текст "Поле не может быть пустым"), которое является частью интерфейса приложения.

**Фактический результат (Actual result):**
Появляется нативное системное всплывающее окно браузера (alert) с текстом "Введите название задачи!". Окно выглядит чужеродно на фоне дизайна приложения.


## BUG-002: Нарушение верстки при вводе длинного текста без пробелов

**Статус:** Закрыт (Closed)
**Приоритет (Priority):** Средний (Medium)
**Серьезность (Severity):** Средняя (Major)
**Окружение (Environment):** Windows 11, Chrome (157.0.8103.39 (64 бит)), `http://127.0.0.1:5000`
**Предусловия (Preconditions):**
1. Приложение запущено локально (`python app.py`).
2. Открыта главная страница.

**Шаги воспроизведения (Steps to reproduce):**
1. Ввести в поле ввода длинную строку без пробелов (например, нажать клавишу на 15 секунд).
2. Нажать кнопку "Добавить".

**Ожидаемый результат (Expected result):**
Длинный текст автоматически переносится на новую строку (word-wrap), не нарушая границы интерфейса. Горизонтальная полоса прокрутки отсутствует.

**Фактический результат (Actual result):**
Текст вылезает за пределы белого блока, растягивает страницу по горизонтали и вызывает появление горизонтальной полосы прокрутки.

**Статус:** Открыт (Open)
**Приоритет (Priority):** Низкий (Low)
**Серьезность (Severity):** Незначительная (Minor)
**Окружение (Environment):**  Windows 11, Chrome (157.0.8103.39 (64 бит)), `http://127.0.0.1:5000`

**Шаги воспроизведения (Steps to reproduce):**
1. Нажать на красную кнопку "Удалить" у любой задачи.

**Ожидаемый результат (Expected result):**
Появляется стилизованное модальное окно внутри интерфейса приложения.

**Фактический результат (Actual result):**
Появляется нативное системное всплывающее окно браузера (confirm).
